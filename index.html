Hướng Dẫn Cài Đặt & Chạy

Sử dụng ngay trong 3 bước

Kho lưu trữ my-cli-tools được đóng gói độc lập theo từng thư mục công cụ, bạn có thể clone toàn bộ hoặc chỉ dùng công cụ mình cần.

Mở PowerShell hoặc Command Prompt và chạy lệnh clone repository chính thức:

powershell / cmd 
PS>git clone https://github.com/minhtrong67/my-cli-tools.git
PS>cd my-cli-tools
Sau khi tải về, vào thư mục công cụ mong muốn (ví dụ shutdown-scheduler hoặc random-rename) và nhấp đúp file .bat tương ứng để chạy.

Cần cho Random Rename (Python) cùng YouTube MP3 Downloader và File Converter (FFmpeg):

winget package manager (Khuyên dùng) 
PS>winget install Python.Python.3.11 Gyan.FFmpeg

⚠️ Lưu ý: Nếu cài Python thủ công từ python.org, hãy tích chọn "Add python.exe to PATH" khi cài đặt.

Nếu bạn muốn tự biên dịch ứng dụng Hẹn giờ tắt máy từ mã nguồn C (sử dụng MinGW-w64):

gcc / mingw64 build command 
# Biên dịch tài nguyên manifest & icon
x86_64-w64-mingw32-windres app.rc -O coff -o app_res.o

# Biên dịch mã nguồn C Win32
x86_64-w64-mingw32-gcc -O2 -mwindows -municode -finput-charset=UTF-8 -fexec-charset=UTF-8 \
    -o shutdown-scheduler.exe shutdown_scheduler.c app_res.o -lcomctl32 -lshell32 -ladvapi32

Xử lý sự cố thường gặp (Troubleshooting)

1. Menu chuột phải không xuất hiện sau khi chạy install.bat? expand_more
Do Windows Explorer chưa kịp cập nhật cache registry. Bạn hãy mở Task Manager (Ctrl + Shift + Esc), tìm mục Windows Explorer trong danh sách và bấm chuột phải chọn Restart.
2. Windows SmartScreen hiển thị cảnh báo khi chạy shutdown-scheduler.exe? expand_more
Do file thực thi được biên dịch trực tiếp từ mã nguồn C cá nhân và chưa mua chứng chỉ số thương mại (code signing). Mã nguồn công khai trong repo để bạn tự kiểm tra. Nếu tin tưởng, bạn chỉ cần chọn "More info" (Xem thêm) > bấm "Run anyway" (Vẫn chạy).
3. Báo lỗi thiếu FFmpeg khi tải nhạc YouTube hoặc chuyển video sang GIF? expand_more
Mở PowerShell và chạy lệnh winget install ffmpeg, sau đó tắt đi mở lại terminal để hệ thống nhận diện biến môi trường PATH.
